# Free CDL Practice Questions & CDL Test Requirements Dataset

Open study material for the U.S. commercial driver's license (CDL) knowledge tests.

- **25 original practice questions** (`data/questions.json`) with answers and the rule or manual section behind each one. Written from scratch; no manual text is copied.
- **Source-linked dataset** (`data/cdl-knowledge-test-requirements-2026.csv`) of federal (49 CFR 380/383) and state (CA, TX, FL, NY, PA) knowledge-test requirements, retrieved 2026-10-25.

Live viewer: enable GitHub Pages (Settings → Pages → Deploy from branch `main`, root).

Want full-length, state-specific practice tests? See **[CDL Prep Hero](https://cdlprephero.com)** — also on the [App Store](https://apps.apple.com/us/app/cdl-prep-hero/id6814061950) and [Google Play](https://play.google.com/store/apps/details?id=com.cdlpreppro.app).
